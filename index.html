My professional experience and contributions

TATA Motors

Full Stack Developer Intern

June 2026 - July 2026 On-Site

Tata Motors needed a way for EV owners to locate nearby charging stations and reserve charging slots in real time, reducing wasted trips to unavailable or occupied stations. I built a full-stack platform on the MERN stack (MongoDB, Express, React, Node.js) that lets users search for charging stations by location, view live slot availability on an interactive map and book or cancel a slot, all secured behind JWT-based authentication.

  • Designed and built the interactive station-locator map using Leaflet, with real-time availability status pulled from the backend.
  • Built RESTful APIs for slot booking and cancellation, including a rule-based recommendation engine that factors in cost estimation.
  • Implemented secure authentication and authorization with JWT sessions, bcrypt password hashing and protected API routes
  • Worked directly with Tata Motors' engineering team to align the feature with existing EV ecosystem requirements
